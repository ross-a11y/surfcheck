# Surfcheck

A simple page for checking coastal webcam images in one place.

Open `index.html` in a browser to view it locally. To add or change a webcam,
edit its card in `index.html`: update the heading, image URL, alt text and
link URL.

To publish with GitHub Pages, enable Pages in the repository settings and
select **Deploy from a branch**, then choose the branch containing the site
and the `/ (root)` folder. Webcam images are hosted by their respective
providers and may be unavailable if a provider is offline or blocks requests.
